# Guion para la presentación oral

1. Explicar la problemática del registro en papel.
2. Presentar el objetivo general y los objetivos específicos.
3. Explicar HTML, CSS, JavaScript, Node.js, Express, PostgreSQL, GitHub y Render.
4. Mostrar las tablas y relaciones de la base de datos.
5. Explicar la comunicación entre frontend, backend y API REST.
6. Registrar un estudiante ficticio y mostrar la validación de DNI único.
7. Tomar asistencia en un curso, indicando fecha y jornada, y mostrar P, A, T y AJ.
8. Consultar historial, estadísticas y exportación CSV.
9. Acceder a la URL de Render una vez desplegado.
10. Responder preguntas sobre autenticación, hash, sesiones, persistencia y restricciones de duplicados.

Utilizar únicamente datos ficticios durante la exposición.
